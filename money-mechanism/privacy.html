Privacy Policy

Last updated: October 9, 2026

This policy describes how Money Mechanism Uploader ("the app") handles data. The app is a personal tool operated by the owner of this site to manage their own YouTube channel, The Money Mechanism.

Data the app accesses

With the account owner's permission, the app uses the YouTube Data API to upload videos, thumbnails and captions to the owner's channel, schedule them, add them to playlists, post the channel's own comments and read and update the status of those videos. It uses the YouTube Analytics API to read the channel's own view and watch-time statistics. The permissions requested are youtube.upload, youtube, youtube.force-ssl and yt-analytics.readonly.

How data is stored

OAuth tokens and statistics are stored only on the owner's own computer. The app has no server, does not collect data about viewers, and does not store, sell or share any user data with third parties.

Use of Google user data

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time from Google Account permissions.

Contact

Questions about this policy can be sent via GitHub.
