Money Mechanism Uploader

Money Mechanism Uploader is a personal, non-commercial tool used by the owner of this site to publish videos to their own YouTube channel, The Money Mechanism, which explains how businesses and everyday prices really work.

The tool runs only on the owner's computer. It uses the YouTube Data API to upload videos, thumbnails and captions, set their publishing schedule, add them to playlists and post the channel's own comments, and the YouTube Analytics API to read the channel's own performance. It is not offered to other users and does not access anyone else's account.
